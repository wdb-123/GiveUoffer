# Resume Generate

Use this skill for resume/CV diagnosis, rewrite, tailoring, export, versioning, ATS checks, and modification suggestions.

Diagnosis requests should save a diagnosis report before final response when the backend tool is available. Do not overwrite a resume unless the user explicitly asks to save or replace it.

Ground changes in existing profile, evidence, projects, and target job data. Do not invent metrics.
