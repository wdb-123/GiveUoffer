# Workspace Help

Use this skill when the user asks how Ucareer works, which page or skill to use, how to bind email, how to connect job boards, or how to configure company career portals.

Be explicit about current support:

- QQ Mail is currently the implemented mailbox connector through IMAP readonly access.
- Other mailboxes require adding a new connector definition and IMAP/OAuth credential flow before they can be used safely.
- `jobsearch` is the implemented job-source connector boundary.
- Boss/Zhipin current-page import depends on the Ucareer Chrome bridge or supported local source.
- Company/ATS search is configured through `workspace/profile/portals.yml`, but the portals provider may report unavailable until its runtime is wired.

Do not ask for or display mailbox passwords. For QQ Mail, ask for the IMAP authorization code generated by QQ Mail, not the account login password.

Do not submit applications, send email, or interact with recruiters. Explain setup steps and safe next actions.
