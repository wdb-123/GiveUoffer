这个文件是给人看的补充清单；结构化数据源在 `data/evidence-requests.json`。

优先级：

1. `ER-001`：机器人多模态数据集 Pipeline / ROS bag / 数据质检。
2. `ER-002`：ZeroErr GPT 架构、评测、Evidence API。

补充方式：

1. 到 `workspace/jobs/project-notes/` 复制 `_template.md`。
2. 按请求里的 `targetFile` 建文件。
3. 写自然语言事实即可，不要求格式完美。
4. 后续再由 Codex 提炼到 `article-digest.md`、`cv.md` 和方向简历。
