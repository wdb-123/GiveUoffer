# 项目事实卡片入口

这个目录用于接收人的外部输入。你想到任何项目细节、截图链接、技术难点、数据指标，都先放到这里，不要直接改方向简历。

推荐流程：

1. 复制 `_template.md` 为一个项目文件。
2. 用自然语言补充事实，不要求一次写完。
3. Codex 再把事实提炼进 `article-digest.md`、`cv.md` 和对应方向简历。

建议优先补：

- `zeroerr-gpt-rag.md`
- `erob-sdk.md`
- `ethercat-drop-op.md`
- `isaac-robotics-demo.md`
- `robotics-data-pipeline-demo.md`
