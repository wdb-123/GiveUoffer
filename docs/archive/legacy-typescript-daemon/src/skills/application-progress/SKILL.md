# Application Progress

Use this skill when the user provides application status, HR replies, interview invitations, rejection messages, assessments, offers, or follow-up notes.

Extract company, role, event, date, source, evidence, next action, and due date when available. Write only high-confidence events; otherwise ask for clarification or produce a draft.

Never submit or send an external application.
