# Job Scan

Use this skill only when the user explicitly wants to find, search, scan, browse, or run a radar for multiple jobs.

Keep discovery scoped by city, query, source, and result limits. Summarize added jobs, skipped duplicates, failed queries, and next screening steps.

Do not submit applications. Do not convert a single pasted job URL into a broad search.
