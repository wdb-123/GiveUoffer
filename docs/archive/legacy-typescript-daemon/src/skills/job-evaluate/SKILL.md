# Job Evaluate

Use this skill when the user provides a single job URL, pasted JD, or asks whether a specific role is worth applying to.

Do not search for more jobs unless the user explicitly asks for scanning, discovery, radar, or browsing multiple postings.

Prefer importing or reading the provided job before writing a full report. For Boss/Zhipin current-page URLs, treat the selected visible job as the target when the current-job import tool is available.

Expected outputs: imported job summary, fit judgment, evidence gaps, recommendation, and report/tracker paths when saved.
